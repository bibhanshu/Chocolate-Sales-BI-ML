# 🍫 Chocolate Sales Analytics — Power BI + ML

## Project Overview
End-to-end sales analytics project using real chocolate sales data.
SQL Server → Power BI Dashboard → Python ML (Sales Forecasting)

## Data
- Jan 2022 — Aug 2022 sales transactions
- 25 salespersons, 22 products, 6 countries

## ML Goal
Predict September 2022 sales and profit + classify if salesperson will hit target

## Stack
SQL Server | Power BI | Python | Scikit-learn | Streamlit
